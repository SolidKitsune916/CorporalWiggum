<task type="auto">
  <name>Task 2: Implement start command</name>
  <files>
    cli/src/commands/start.ts
  </files>
  <action>
    Create cli/src/commands/start.ts:

    Import Commander, chalk, ora, spawn from child_process.
    Import resolveProjectOrExit from lib/resolve.
    Import getProcessRegistry, type LoopMode.
    Import path, fs for finding loop.sh.

    Export startCommand:
    - Command: 'start <project> [mode]'
    - Description: 'Start a loop for a project'
    - Argument: project (required) - "Project name, path, or ID"
    - Argument: mode (optional) - default 'build', choices: build, plan, plan-slc, plan-work
    - Option: -n, --max-iterations <n> - "Maximum iterations"
    - Option: -w, --work-scope <scope> - "Work scope (for plan-work mode)"

    Action (async):
    1. Resolve project using resolveProjectOrExit
    2. Check if project already has running loop (getProcessRegistry().getActiveLoop(projectId))
       - If yes, error: "Loop already running for {project.name}"
    3. Find loop.sh:
       - First check project.path/loop.sh
       - Then check RALPH_DIR env var
       - Then check relative to CLI (../../loop.sh from cli/)
       - Error if not found
    4. Start spinner: "Starting {mode} loop for {project.name}..."
    5. Spawn process:
       - bash loop.sh with args based on mode
       - cwd: project.path
       - detached: true (daemon mode)
       - stdio: 'ignore' (detach from terminal)
       - Call unref() so CLI can exit
    6. Wait 500ms, verify process alive with process.kill(pid, 0)
    7. If alive:
       - Register with ProcessRegistry.registerLoop()
       - spinner.succeed: "Loop started (PID: {pid})"
    8. If dead:
       - spinner.fail: "Loop failed to start"
       - process.exit(1)

    Note: Unlike dashboard LoopController which stays attached, CLI starts loop as daemon.
  </action>
  <verify>
    - ralph start --help shows usage and options
    - ralph start <valid-project> starts loop (check with ralph status)
    - ralph start <already-running> shows "already running" error
    - ralph start <invalid-project> shows "not found" error
    - Started process continues after CLI exits
  </verify>
  <done>`ralph start <project>` spawns loop as daemon and registers with ProcessRegistry</done>
</task>

<task type="auto">
  <name>Task 3: Implement stop command</name>
  <files>
    cli/src/commands/stop.ts
    cli/src/ralph.ts
  </files>
  <action>
    Create cli/src/commands/stop.ts:

    Import Commander, chalk, ora, readline/promises.
    Import resolveProjectOrExit from lib/resolve.
    Import getProcessRegistry, GracefulShutdown.

    Export stopCommand:
    - Command: 'stop [project]'
    - Description: 'Stop a running loop'
    - Argument: project (optional) - "Project name, path, or ID"
    - Option: -a, --all - "Stop all running loops"
    - Option: -f, --force - "Force kill without graceful shutdown"
    - Option: -y, --yes - "Skip confirmation for --all"

    Action (async):
    1. If options.all:
       - Get all active loops: registry.getAllActiveLoops()
       - If empty, print "No running loops" and exit
       - If not options.yes, prompt confirmation: "Stop ALL {n} running loops? [y/N]"
         - Use readline/promises to read answer
         - If not 'y' or 'yes', print "Aborted" and exit
       - For each loop:
         - Start spinner: "Stopping {projectId}..."
         - Call gracefulShutdown.stopAndVerify(pid, force ? 0 : 5000)
         - Call registry.unregisterLoop(sessionId, projectId, false)
         - spinner.succeed or fail based on result
       - Print summary: "Stopped {n} loops"
    2. Else (single project):
       - Require project argument, error if missing
       - Resolve project using resolveProjectOrExit
       - Get active loop: registry.getActiveLoop(projectId)
       - If no loop, error: "No running loop for {project.name}"
       - Start spinner: "Stopping loop for {project.name}..."
       - Call gracefulShutdown.stopAndVerify(session.pid, force ? 0 : 5000)
       - Call registry.unregisterLoop(session.id, projectId, false)
       - If success: spinner.succeed("Stopped via {result.method} ({result.durationMs}ms)")
       - If failed: spinner.fail("Failed to stop loop")

    Update cli/src/ralph.ts:
    - Import startCommand and stopCommand
    - Add both commands to program
    - Rebuild: cd cli && npm run build
  </action>
  <verify>

    - ralph stop <running-project> stops loop, verified with ralph status
    - ralph stop <not-running-project> shows "no running loop" error
    - ralph stop --all prompts for confirmation
    - ralph stop --all --yes skips confirmation
    - ralph stop --force uses SIGKILL immediately
  </verify>
