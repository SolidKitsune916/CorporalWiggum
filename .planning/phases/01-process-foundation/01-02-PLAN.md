Create GracefulShutdown class for reliable process termination:

1. Define StopResult interface:
   - success: boolean
   - method: 'sigterm' | 'sigkill' | 'already_dead' | 'failed'
   - durationMs: number (how long termination took)

2. Implement GracefulShutdown class:

   - `isProcessAlive(pid: number)`: Signal 0 check
     - Return true if process exists
     - Handle EPERM as alive (process exists, no permission)
     - Return false for ESRCH (no such process)

   - `async stopAndVerify(pid: number, timeoutMs: number = 5000)`: Main method
     - Check if already dead first
     - Send SIGTERM (or process group -pid on Unix)
     - Poll every 100ms until dead or timeout
     - If still alive, send SIGKILL
     - Final verification with 200ms wait
     - Return StopResult with method used

   - `killProcessGroup(pid: number, signal: string)`: Platform-aware killing
     - On Windows: Use `taskkill /pid ${pid} /T /F` via execSync
     - On Unix: Try process.kill(-pid, signal) for process group
     - Fall back to process.kill(pid, signal) if group kill fails

3. Default timeout: 5000ms (5 seconds)

4. Import exec/execSync from 'child_process' for Windows taskkill

Pattern from research:
```typescript
async stopAndVerify(pid: number, timeoutMs: number = 5000): Promise<StopResult> {
  const startTime = Date.now();

  if (!this.isProcessAlive(pid)) {
    return { success: true, method: 'already_dead', durationMs: 0 };
  }

  // Send SIGTERM to process group
  this.killProcessGroup(pid, 'SIGTERM');

  // Poll until dead or timeout
  const deadline = Date.now() + timeoutMs;
  while (Date.now() < deadline) {
    await this.sleep(100);
    if (!this.isProcessAlive(pid)) {
      return {
        success: true,
        method: 'sigterm',
        durationMs: Date.now() - startTime
      };
    }
  }

  // Escalate to SIGKILL
  this.killProcessGroup(pid, 'SIGKILL');
  await this.sleep(200);

  const stillAlive = this.isProcessAlive(pid);
  return {
    success: !stillAlive,
    method: 'sigkill',
    durationMs: Date.now() - startTime
  };
}
```

     const result = await this.gracefulShutdown.stopAndVerify(pid);

     if (result.success) {
       this.emitLog(
         `Loop stopped via ${result.method} (${result.durationMs}ms)`,

         `Failed to stop loop after ${result.durationMs}ms`,

     if (result.success && result.method !== 'already_dead') {

     }
   }
