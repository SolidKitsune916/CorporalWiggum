  <name>Task 1: Create file tailing utility</name>
  <files>
    cli/src/lib/tail.ts
  </files>
  <action>
    Create cli/src/lib/tail.ts:

    Import fs, fs/promises, path.
    Import chalk for optional styling.

    Export readLastLines(filePath: string, n: number): Promise<string[]>
    - Read file content
    - Split by newlines
    - Return last n lines (filter empty)
    - Handle file not found gracefully (return [])

    Export tailFile(filePath: string, options?: TailOptions): Promise<void>
    - Options: { initialLines?: number, onLine?: (line: string) => void }
    - Default initialLines: 20
    - Default onLine: console.log

    Implementation:
    1. Check file exists, throw if not
    2. Read last initialLines and output via onLine
    3. Get initial file size as position marker
    4. Print separator: chalk.dim("--- Streaming. Press Ctrl+C to detach ---")
    5. Set up fs.watch on the file
    6. On 'change' event:
       - Get new file size
       - If larger than position:
         - Open file, seek to position, read new bytes
         - Convert to string, split by newlines
         - Output each new line via onLine
         - Update position to new size
    7. Set up SIGINT handler:
       - watcher.close()
       - Print chalk.dim("\nDetached.")
       - process.exit(0)
    8. Return promise that never resolves (keeps watching)

    Export stopTailing(): void
    - For programmatic stop (not just Ctrl+C)
    - Closes watcher if active

    Handle edge cases:
    - File deleted while watching: exit gracefully
    - File truncated: reset position to 0
  </action>
  <verify>
    - cd cli && npx tsc --noEmit passes
    - readLastLines returns correct number of lines
    - tailFile streams new content as file grows
    - Ctrl+C exits cleanly
  </verify>
  <done>File tailing utility created with fs.watch and position tracking</done>
</task>

<task type="auto">
  <name>Task 2: Implement attach command</name>
  <files>
    cli/src/commands/attach.ts
  </files>
  <action>
    Create cli/src/commands/attach.ts:

    Import Commander, chalk, path, fs.
    Import resolveProjectOrExit from lib/resolve.
    Import getProcessRegistry from lib/database.
    Import tailFile from lib/tail.

    Export attachCommand:
    - Command: 'attach <project>'
    - Description: 'Stream live output from a running loop'
    - Argument: project (required) - "Project name, path, or ID"

    Action (async):
    1. Resolve project using resolveProjectOrExit
    2. Check for running loop: registry.getActiveLoop(projectId)
       - If no loop, error: "No running loop for {project.name}"
       - Hint: "Start one with: ralph start {project.name}"
    3. Find log file:
       - Primary: {project.path}/ralph.log
       - If symlink, resolve to actual file
       - If not found, error: "No log file found"
    4. Print header:
       - chalk.bold("Attached to {project.name}")
       - chalk.dim("Mode: {session.mode} | PID: {session.pid} | Started: {formatted time}")
    5. Call tailFile with log path:
       - initialLines: 30
       - onLine: console.log (default)
    6. The promise from tailFile never resolves (user must Ctrl+C)

    Note: Unlike stop, attach does NOT terminate the loop. Ctrl+C only detaches.
  </action>
  <verify>
    - ralph attach --help shows usage
    - ralph attach <running-project> shows header and streams output
    - Ctrl+C detaches cleanly without stopping loop
    - ralph attach <not-running> shows error with hint
    - ralph attach <no-log-file> shows appropriate error
  </verify>
  <done>`ralph attach <project>` streams live output with clean detachment</done>
</task>
