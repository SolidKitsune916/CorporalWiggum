<objective>
Create the PID file infrastructure and central process registry that tracks all running loops across all projects.

Purpose: This is the foundation for reliable process management. Without persistent PID files, dashboard restarts lose track of running loops. Without a central registry, we can't see loops from other projects.

Output: PidFileManager class for file operations, ProcessRegistry class that wraps SessionRepository and syncs with PID files, integrated into LoopController.
</objective>

  <name>Task 2: Create ProcessRegistry class</name>
  <files>dashboard/server/processManager/ProcessRegistry.ts, dashboard/server/processManager/index.ts</files>
  <action>
Create ProcessRegistry class that provides a central view of all running loops:

1. ProcessRegistry class:
   - Constructor takes SessionRepository and PidFileManager
   - `registerLoop(projectId, projectPath, pid, mode)`:
     - Create session in SessionRepository
     - Write PID file via PidFileManager
     - Return session ID
   - `unregisterLoop(sessionId, projectId)`:
     - Delete PID file
     - Mark session completed in SessionRepository
   - `getAllActiveLoops()`:
     - Get active sessions from SessionRepository
     - Return array with session + process liveness info
   - `getActiveLoop(projectId)`:
     - Get active session for specific project
   - `syncWithPidFiles()`:
     - Compare PID files with database
     - Return orphans (PID file exists but no matching session, or vice versa)
   - `isProcessAlive(pid: number)`:
     - Use signal 0 check (process.kill(pid, 0))
     - Handle EPERM as "alive" (process exists but no permission)

2. Export singleton getter `getProcessRegistry()`:
   - Lazy initialization
   - Use getSessionRepository() and new PidFileManager()

3. Create index.ts barrel export:
   - Export PidFileManager, PidFileContent from './PidFileManager.js'
   - Export ProcessRegistry, getProcessRegistry from './ProcessRegistry.js'

Pattern for process check (from research):
```typescript
isProcessAlive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (err: any) {
    return err.code === 'EPERM';
  }
}
```
