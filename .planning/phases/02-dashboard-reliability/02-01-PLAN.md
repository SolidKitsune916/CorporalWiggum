<task type="auto">
  <name>Task 2: Emit starting/stopping states from LoopController</name>
  <files>dashboard/server/loopController.ts</files>
  <action>
    Modify start() and stop() methods to emit intermediate states:

    **In start() method**, after spawning the process but before registration completes:
    1. Set status with `starting: true` immediately after spawn
    2. After successful ProcessRegistry.registerLoop(), set `starting: false`

    ```typescript
    // In start(), right after this.process = spawn(...)
    this.status = {
      running: true,
      starting: true,  // Indicate startup in progress
      mode,
      iteration: 0,
      maxIterations: maxIterations || 0,
      workScope,
      startedAt: new Date(),
      pid,
    };
    this.emit('status', this.status);

    // In the .then() callback after registerLoop succeeds:
    this.status = { ...this.status, starting: false };
    this.emit('status', this.status);
    ```

    **In stop() method**, emit stopping state before calling GracefulShutdown:
    1. Set `stopping: true` before calling stopAndVerify()
    2. The close event handler already clears running, which will clear stopping implicitly

    ```typescript
    // At the beginning of stop(), after validating process exists
    this.status = { ...this.status, stopping: true };
    this.emit('status', this.status);
    this.emitLog('Stopping loop...', 'info');
    ```

    Ensure the 'close' event handler sets stopping: false when resetting status.
  </action>
  <verify>
    1. Start a loop and observe WebSocket message contains `starting: true` then `starting: false`
    2. Stop a loop and observe WebSocket message contains `stopping: true`
    3. After stop completes, status should have `running: false, stopping: false`
  </verify>
  <done>LoopController emits starting/stopping flags during state transitions</done>
</task>
